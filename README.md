## Setup

### Backend
1. cd backend
2. npm install
3. create .env file (PORT, DB_FILE, ADMIN_TOKEN)
4. node db/seed.js
5. npm run dev

### Frontend
1. cd frontend
2. npm install
3. npm start

Proxy API calls: frontend/package.json -> "proxy": "http://localhost:3001"
